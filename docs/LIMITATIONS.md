# 既知の制約

## OCR

OCRは100%の正確性を保証しません。

特に次の条件では誤認識が増えます。

- 低解像度
- 強い傾き
- かすれ
- 背景ノイズ
- 罫線と文字の重なり
- 印影
- 小さい文字
- 特殊フォント
- 崩した手書き
- 走り書き

## 手書き

丁寧な楷書は認識できる場合がありますが、自由筆記の日本語手書きは参考対応です。

手書き対応を主目的とするOCRではありません。

## 表・帳票構造

見た目上同じ帳票でも、OCRが取得する文字ボックス数や順序は変化することがあります。

そのため、次は保証しません。

- 全ファイルで完全に同じ列位置
- 空欄位置の完全復元
- 結合セルの完全な復元
- Key / Value対応の完全自動判定

## Smart Merge

近い文字列を距離や文字種から結合します。

誤結合を防ぐためのルールを持ちますが、次のような誤りは起こり得ます。

- 本来別項目の文字列を結合
- 本来1項目の文字列を分離
- ハイフン補完の誤推定

原OCR文字列は可能な限り保持します。

## キーワード整列

キーワードを基準に横持ち列を寄せる補助機能です。

文書全体の意味構造を理解して完全整列する機能ではありません。

## PDF判定

PDF内に十分な文字レイヤーが存在する場合は直接抽出します。

文字量が少ない場合はスキャンPDFとみなしOCRへ切り替えます。

特殊なPDFでは意図と異なる判定になる可能性があります。

必要に応じて `PDFを強制OCRする` を利用してください。

## 業務マスターデータ化

本ツールは、業務マスターデータ作成の前処理を支援しますが、抽出内容の業務的な正当性を自動保証しません。

特に規格・仕様・要件書では、次のような情報が重要です。

- 例外条件
- 適用範囲
- AND / OR等の複合条件
- 別表・別章への参照
- 注記
- 改訂版による差異
- 単位や測定条件

これらを文字抽出だけで完全に構造化・判定することは保証しません。

## 性能

PaddleOCRは画像認識処理を行うためCPU・メモリを比較的大きく使用します。

大量ファイル、詳細解析、高DPIでは処理時間と発熱が増えます。

## 重要用途

次のような用途では結果をそのまま確定データとして使用しないでください。

- 会計
- 契約
- 法務
- 品質保証
- 安全管理
- 規格適合判定
- 医療
- 人事判断
- 金銭支払
- その他誤りが重大な影響を持つ処理

必ず原本と照合し、必要な承認・確認プロセスを通してください。

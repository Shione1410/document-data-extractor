# 使い方

## 1. ファイルを追加する

次のどちらかを使用します。

- `ファイルを追加`
- `フォルダを指定`

対応形式:

- `.xlsx`
- `.xlsm`
- `.csv`
- `.docx`
- `.pdf`

フォルダ指定では、対応ファイルをまとめて追加できます。

## 2. OCRモードを選ぶ

OCRが必要なスキャンPDFでは次の3モードを利用できます。

### 高速
速度優先。大量文書の一次確認向けです。

### 標準（推奨）
速度と精度のバランスを重視します。

### 詳細解析
向き・歪み・文字行補正を利用します。処理時間は長くなります。

詳細解析が必ず最高精度になるとは限りません。

## 3. OCR環境を確認する

初回利用時やexe版を別PCへ配置した場合は、`OCR環境テスト` を実行してください。

正常な場合は、Paddle / PaddleOCRの読み込みとOCRエンジン初期化が完了します。

初回はOCRモデルの取得が発生し、時間がかかる場合があります。

## 4. 解析を開始する

文字レイヤーを持つPDFは原則として直接読み取ります。

文字量が少ないPDFはスキャンPDFと判断し、OCRへ切り替えます。

Excel / CSV / WordはOCRを使用せず、文書構造から直接抽出します。

必要に応じて `PDFを強制OCRする` を利用できます。

## 5. 結果を確認する

通常表示では次を表示します。

- ファイル
- 修正後文字列
- OCR信頼度
- 確認

`詳細情報を表示` を押すと次の内部情報を確認できます。

- ページ / シート
- 抽出種別
- OCR元文字列
- 判定
- 判定元

## 6. 修正・分類する

OCR結果は直接編集できます。

Key / Value / 文字列 / 記号 / 不要 の分類も手動修正できます。

手動分類を教師として残りのレコードを半自動分類することもできます。

この分類は、業務上の意味を完全に理解するAI判定ではなく、既存の手動例との類似度を利用した補助機能です。

## 7. キーワード整列

横持ち出力で特定キーワードの位置を基準に揃えたい場合に使用します。

例:

`製品番号`

キーワード整列は、すべての項目を正しく同一列へ揃えることを保証するものではありません。

適用時は品質レベルが `Silver Candidate` になります。

## 8. 出力

初期状態で出力対象となる列:

- ファイル
- 修正後文字列

必要に応じて他の情報を追加できます。

### 横持ち
1ファイルを1行として扱い、抽出項目を横方向へ展開します。

### 縦持ち
1レコードを1行として扱います。

DB投入や分析の前処理では縦持ちの方が扱いやすい場合があります。

## 9. OCR信頼度

OCRした文字列には数値が入ります。

Excel / CSV / Word / 文字PDFなど、直接取得したデータにはOCR信頼度が存在しないため `―` と表示します。

## 10. 業務マスターデータへ利用する場合

本ツールの抽出結果を、規格・仕様・検査条件などの業務マスターデータ作成に利用する場合は、次の流れを推奨します。

```text
元文書
  ↓
抽出（Bronze）
  ↓
分類・整列（Silver Candidate）
  ↓
原文との照合・修正
  ↓
検証済みマスターデータ
  ↓
検索・照合・要件判定などの後続アプリ
```

重要な判定に使うデータは、抽出結果をそのまま確定値として使用せず、必ず原文と照合してください。
